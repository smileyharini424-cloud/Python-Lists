# Python Lists

## Explanation

A list is an ordered and mutable collection of elements in Python. Lists can contain multiple values of different data types.

Lists are created using square brackets `[]`.

## Problem Statement

Write a Python program that creates a list, displays its elements, accesses individual elements, modifies an element, and demonstrates list slicing.

## Features

* Creates a list
* Displays list elements
* Accesses elements using indexing
* Modifies list elements
* Uses negative indexing
* Demonstrates list slicing

## How It Works

The program creates a list containing several student names.

It then:

* Displays the complete list
* Accesses the first and last elements
* Changes one element
* Extracts a portion of the list using slicing

## Technologies Used

* Python 3

## Program Flow

1. Start the program.
2. Create a list of names.
3. Display the list.
4. Access list elements using indexes.
5. Modify an element.
6. Perform list slicing.
7. Display the results.
8. End the program.

## Sample Output

```text id="j6c3vz"
Original List: ['Harini', 'Anu', 'Ravi', 'Kiran']
First Element: Harini
Last Element: Kiran
Modified List: ['Harini', 'Priya', 'Ravi', 'Kiran']
Sliced List: ['Harini', 'Priya', 'Ravi']
```
